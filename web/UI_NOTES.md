# 网页使用与验收说明

前端为同源无构建 HTML/CSS/JS。通过后台地址访问，不要直接以 file:// 打开 index.html。

## 本地演示路径

1. 展开底部“本机管理与接入”，输入服务器的管理令牌。
2. 左侧选择冒险、规则与主持模型。默认“模拟 KP”；未配置的真实模型不可选。
3. 开启冒险后显示公共开场与房间 ID / 邀请码。填写左侧冒险者名称，加入同一个房间。房主身份与玩家身份同时保留。
4. 中央输入对话；也可切换检定。右侧相邻地点按钮可带领全队移动。
5. 右侧房主管理可启动演示战斗；中央选择攻击目标、提交攻击或结束回合，观察事件、HP 与耐力变化。
6. 同一标签页刷新会从 sessionStorage 恢复身份并读取服务器存档。另一标签页用房间 ID、邀请码与新名称加入。
7. 完整存档仅房主可导出，包含主持秘密。管理面板恢复文件后，在“认领恢复的原角色”选择并切换；恢复的身份令牌全部轮换。
8. QQ 本地模拟：同时持有房主与玩家身份，填写模拟 QQ 用户 ID 并绑定，再提交模拟文字。此流程不连接真实 QQ。

## 状态与边界

- 只读 provider 状态不代表已保存配置。API key 仅在服务器设置环境变量，网页没有密钥输入框。
- 管理令牌、房主/玩家令牌与恢复身份仅留在当前标签页 sessionStorage，不使用 localStorage；清除房间身份按钮会移除房间相关令牌。
- 房主响应在前端再次过滤为公共事件；只在玩家投影下渲染本人的个人札记。前端不请求完整剧本。
- 行动与 QQ 模拟请求在结果未知时保留原 requestId/eventId；409 刷新版本并保留输入。提交期间禁用按钮，避免重复点击。
- 每 6 秒读取当前房间；隐藏标签页暂停轮询。旧版本或旧房间的迟到响应不会覆盖当前显示。
- 位置图是装饰示意，实际地点、NPC 与相邻地点按钮来自服务器公开 scene 投影。
- 真实模型费用、模型输出质量与真实 QQ 网关没有在前端工作中联调。

## 当前检查

- `node --check web/app.js` 通过。
- HTTP 请求路径、字段与鉴权已按 docs/HTTP_API.md 接线。
- 浏览器真实流程与窄屏视觉抽查由中枢统一执行，避免多个执行者操作同一浏览器。

## v0.2 自然语言主持

- 中央默认输入通过 say{text} 进入导演。明确的玩家行动直接执行；歧义、多动作或条件意图先澄清，玩家回复后继续。主持人不能自动替角色选择。手动检定、攻击、移动、交互、休整、撤退仍可选。
- 待确认卡片显示服务器 pending.message 和公开可识别动作/对象，不在 DOM 打印提案原始 payload。仅当前玩家与 pending.actorId 相同、版本一致且未暂停/结束时可确认或取消；使用玩家 token、requestId、expectedVersion、proposalId 提交。409 自动刷新并保留中央草稿。
- 目标、队伍背包、交互卡片与结局仅来自 SessionView 的公开投影。不存在前端完整剧本、隐藏标志、锁定地点解法或硬编码攻略卡片。卡片“执行交互”是玩家明确授权的动作，不会自动执行。
- status=won/lost 后禁用规则行动、移动、交互、房主控制和待确认提案。自然语言输入保留用于服务端允许的聊天；查看和存档导出可用。
- 右侧快捷交互/移动与提案确认/取消不改变中央类型、不清空文字草稿。只有成功提交中央 say 才清空其文字。
- 事件明确标识导演澄清、待确认提案、执行动作、规则结算、剧情事件及结局。顶部“本地演示导演”说明 Mock 的实际能力边界；配置真实 provider 后显示对应模型渠道，并不表示已做真实付费调用验收。
- QQ 本地模拟消息复用 say 的自然语言导演/规则/剧情入口；绑定当前角色后输入行动、澄清回复或确认文字。真实 QQ 网关仍待联调。
- 本轮 node --check 为静态验证；浏览器完整自然语言旅程、提案与窄屏交互由中枢验收。
- 无依赖 VM 假 DOM smoke 已通过：初始化、公开目标/背包/交互渲染、本人提案确认启用/他人禁用、结束后结局显示与规则选项/交互禁用、聊天选项保留。此检查不替代真实浏览器布局或 HTTP 完整旅程。
- 冒险与规则下拉按数值语义版本降序排列，首次默认最高版本；同 ID 的旧版保留可选。刷新目录保留仍有效的已选版本。选项值同时绑定 ID 与版本，摘要精确匹配该版本，创建请求显式发送 scenarioVersion / ruleVersion，避免旧版选项被后台最高版本替代。
