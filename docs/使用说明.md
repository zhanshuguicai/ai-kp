# AI KP 使用说明

> 适用版本：v0.4.0。

## 这是什么

AI KP 让 AI 来当跑团的 KP（主持人），比如克苏鲁的呼唤、D&D 这些团。
- 你把剧本交给它，它会自己读剧本、主持剧情、决定什么时候检定、帮你掷骰。
- 玩家只要用平常说话的方式写"我做什么"就行，不用懂规则，也不用自己掷骰。
- **组织者不会被剧透**：剧本内容只有 AI 看得到，搭团的人可以和其他玩家一起，第一次体验剧情。

---

## 一、准备工作（只需要做一次）

### 1. 安装 Node.js
1. 打开 https://nodejs.org ，下载 **LTS（长期支持）版**，版本号要 22.13 或更高。
2. 一路点"下一步"装好。

### 2. 下载 AI KP
1. 打开 https://github.com/zhanshuguicai/ai-kp/releases ，在最新版本下面下载 **ai-kp-v版本号.zip**。
2. 在下载好的 zip 上**右键 → "全部解压缩"**，放到一个好找的地方，比如 `D:\ai-kp`。

### 3. 准备一个 AI 模型的 API key
推荐用 **OpenRouter**：一个 key 就能用 Claude、Gemini 等多家模型。
1. 打开 https://openrouter.ai ，注册并登录。
2. 在 **Credits** 页面充值，先充 5–10 美元就够试很多次。
3. 在 **Keys** 页面创建一个 key，它以 `sk-or-` 开头。复制下来，**不要发给别人**。

> 也可以用 DeepSeek、OpenAI、Anthropic 或 Google Gemini 官方的 key，或者兼容 OpenAI 格式的第三方中转，设置方法见第三章。
> DeepSeek 国内可以直接访问，用支付宝或微信就能充值：在 https://platform.deepseek.com 注册，充值后在 **API keys** 页面创建 key（以 `sk-` 开头）。

## 二、启动

1. 打开解压出来的文件夹，**双击 `Start-AI-KP.bat`**。
   - 如果 Windows 弹出安全提示，点 **"更多信息" → "仍要运行"**，或者在提示框里点 **"运行"**。
   - 如果提示"没有找到 Node.js"或者"版本太旧"，按第一章装好 Node.js 后再双击。
2. 会弹出一个黑色窗口，几秒后浏览器自动打开 **http://127.0.0.1:3100** 。**玩的时候不要关掉这个黑色窗口**，关掉 AI KP 就停了。
3. 页面右上角要填"管理令牌"：
   - 打开文件夹里的 `data\admin-token.txt`（第一次启动时自动生成），把里面那串字符复制过来；
   - 粘贴进去，点 **连接**；
   - 显示"已连接"就可以了。

> 管理令牌相当于组织者的钥匙，不要发给玩家。

**关闭程序**：直接关掉黑色窗口，或者在窗口里按 `Ctrl + C`。

**升级到新版本**：下载新版本解压到新文件夹，把旧文件夹里的 `data` 文件夹整个复制过去（里面是你的团、剧本和设置），再双击新文件夹里的 `Start-AI-KP.bat`。

> macOS / Linux：在终端里进入解压后的文件夹，运行 `sh start.sh`。
>
> 想从源码运行（开发者）：克隆仓库后运行 `npm install`、`npm run build`、`npm run platform`。

---

## 三、填写 API key

1. 在组织者页面左边点开 **"API 与模型设置"**。
2. "接口"选 **OpenRouter**。
3. 把 key 粘贴到 **"API key"** 一栏。
4. 点 **保存**。下拉框里的"（未配置）"消失，就说明设置好了。

想换默认模型的话：点 **"获取模型列表"**，在"默认模型"框里输入关键词（比如 `flash`、`opus`）就能筛选，候选列表还会显示价格。

**用其他接口时：**

| 接口 | 怎么填 |
|---|---|
| OpenAI 官方 | 接口选 OpenAI，接口模式选 **Responses**，填 key |
| 第三方中转（兼容 OpenAI 格式） | 接口选 OpenAI，接口模式选 **Chat Completions**，"接口地址"填中转给你的地址（一般以 `/v1` 结尾），填 key |
| DeepSeek 官方 | 接口选 DeepSeek，填 key；接口地址留空即可 |
| Anthropic 官方 | 接口选 Anthropic，填 key |
| Google Gemini 官方 | 接口选 Google Gemini，填 key |

**模型怎么选**（以 OpenRouter 为例）：

| 用途 | 推荐 | 说明 |
|---|---|---|
| 整理剧本 | `anthropic/claude-opus-5.5` | 整理得最细，一个剧本只需要整理一次，约 0.3 美元 |
| 主持（追求质量） | `anthropic/claude-opus-5.5` | 叙述自然，主持最稳；约 0.085 美元一轮 |
| 主持（追求省钱） | `google/gemini-3.8-flash` | 约 0.01 美元一轮，便宜很多，但文字稍显堆砌 |
| 写摘要（辅助模型） | `anthropic/claude-haiku-5.5` | 默认就是它，几乎不花钱，不用改 |

> 一场 3 小时左右的团大约 100 轮：用 Opus 约 8–9 美元，用 Flash 约 1 美元。价格会变，以 OpenRouter 页面为准。

**用 DeepSeek 官方接口时：**

| 用途 | 推荐 | 说明 |
|---|---|---|
| 主持 | `deepseek-v4-pro` | 默认就是它，质量更好 |
| 写摘要（辅助模型） | `deepseek-flash` | 默认就是它，非常便宜 |

> DeepSeek 默认会先"思考"再回答，回答更稳但会慢一些。想更快可以在设置里把"推理强度"选成 **none（关闭）**。
> DeepSeek 在工作日的高峰时段（北京时间 9:00–12:00、14:00–18:00）价格是平时的两倍，晚上和周末玩更划算。
> DeepSeek 还没有在本平台用真实对局测试过，第一次使用建议先拿一个不打算玩的剧本试几轮。

## 四、导入剧本

1. 左边点开 **"导入剧本"**。
2. 填剧本标题，选择剧本文件。
   - 目前只支持 **TXT 或 Markdown** 文件。
   - Word 文件（.docx）需要先转换：用 Word 打开 → **文件 → 另存为** → 保存类型选 **"纯文本 (*.txt)"** → 编码选 **UTF-8**。
3. "用于整理剧本的模型"选你配好的接口；模型可以留空，也可以填 `anthropic/claude-opus-5.5`。
4. 点 **导入**。

导入后，AI 会在后台通读剧本，大约 1–2 分钟。
- **AI 会整理出两样东西**：
  - 一份只有 AI 能看到的"KP 指南"，里面有真相、NPC 秘密和线索；
  - 一份给大家看的**无剧透简介**。
- **页面不会显示剧本原文**，你也看不到 KP 指南，这样你自己玩的时候不会被剧透。
- **怎么算整理完**：剧本旁边的状态从"整理中…"变成"已整理"，并显示简介。
- **整理失败**：点 **"重新整理"** 再试一次。

---

## 五、开团

1. 左边点开 **"开新团"**。
2. 依次填写：
   - **团名**：随便起。
   - **剧本**：选刚才导入的剧本，下面会显示它的简介。
   - **规则**：选剧本用的规则，比如"克苏鲁的呼唤 第七版"。
   - **模型供应商**：选你配好的接口；主力模型可以留空，也可以照第三章的推荐填。
   - **玩家**：一行写一位，格式是 `编号,名字`，例如：
     ```
     p1,林雾
     p2,周岚
     ```
     如果你自己也要玩，把自己也写进去。
3. 点 **"开团并生成邀请链接"**。

页面会显示每位玩家的**邀请链接**。注意这些链接**只显示这一次**：
- 点 **复制** 记下来，交给对应的玩家；
- 如果弄丢了，点 **"重新生成全部邀请链接"**，旧链接会全部失效。

## 六、玩家怎么玩

1. 玩家打开自己的邀请链接，就进入了玩家页面。
2. **先填角色卡**：在右边"我的角色卡"里点 **"填入示例"**，把数字改成自己角色的，再点 **"保存角色卡"**。
3. 组织者在自己的页面上点 **"开场"**，AI 会描述开场的情景。
4. 之后玩家在下面的输入框里写自己做什么、说什么，点 **发送**（或按 `Ctrl + Enter`）。

**发言就像平时说话一样，比如：**
- "我仔细翻一翻书桌上的信件。"
- "我对房东说：'这房子以前到底出过什么事？'"
- "我悄悄跟在他后面，别让他发现。"

**玩家不需要**说"我要过侦查"或"我掷个 d100"。要不要检定、用哪个技能、多难，都由 AI 判断；骰子由程序掷，结果会显示在记录里。

**几个小规则：**
- **场外话**（和剧情无关的闲聊）用括号括起来，或者以 `ooc:` 开头，例如"（今天玩到几点？）"。
- **AI 问你要不要冒险**时（比如要不要"孤注一掷"再试一次），直接回答就行，AI 不会替你做决定。
- **只有你能看到的消息**会标成"KP 悄悄告诉你"，其他玩家看不到。
- **暗骰**：有时记录里会出现"KP 进行了一次暗骰"，这是 AI 在暗中检定，结果不会公开。

---

## 七、组织者在游戏中能看什么

组织者页面右边有这些：
- **玩家与邀请**：谁已经进来了，也可以中途加人。
- **模型与用量**：
  - 本团用的是哪个模型；
  - 累计花了多少钱；
  - 想中途换模型或换接口，在这里改，从下一轮开始生效。
- **上下文压缩**：游戏进行得久了，AI 会自动把早期经过写成摘要，免得越来越慢、越来越贵。这里只显示进度，不显示摘要内容。
- **运行诊断**：每一轮用了哪些工具、有没有出错、花了多少 token，**不包含任何剧情**。

---

## 八、游戏结束后复盘

想知道剧本真相、看看 AI 在背后做了什么，可以在页面右下"复盘"里点 **"解锁 KP 视图"**。
- 解锁后能看到全部秘密：剧本真相、KP 笔记、暗骰、威胁时钟。
- **解锁无法撤销**，并且会在游戏记录里通知所有玩家。
- 所以**只在游戏结束后用**。

---

## 九、现在还做不到的

- **只能在这台电脑上玩**：为了安全，程序目前只接受本机访问，邀请链接在别的电脑或手机上打不开。多位玩家可以在这台电脑上各开一个浏览器窗口，轮流发言。联网多人还在计划中。
- **不能直接导入 Word 文件**：需要先另存为 TXT，方法见第四章。
- **简介不能保证零剧透**：程序会拦住照抄秘密的句子，但 AI 用自己的话暗示剧情就拦不住。拿到新剧本时，可以先看看简介写得怎么样。

## 十、常见问题

**打不开 http://127.0.0.1:3100**
- 黑色窗口是不是关了？重新双击 `Start-AI-KP.bat`。
- 黑色窗口里如果有报错，截图后反馈。

**右上角显示"令牌无效"**
- 重新打开 `data\admin-token.txt`，把整串字符完整复制过来，前后不要带空格。

**显示"未配置 API key"、"请检查 API key"或"账户余额不足"**
- 按第三章检查 key 有没有填对；
- 去 OpenRouter 的 Credits 页面看看余额。

**某一轮显示失败**
- 网络波动或 AI 服务暂时出错时会这样。已经掷出的骰子会保留，**再发一次**就行。
- 程序遇到短暂的网络错误会自动重试一次。

**剧本整理失败**
- 点 **"重新整理"**。
- 如果程序在整理过程中被关掉，整理会被标成失败，同样点"重新整理"即可。

**数据存在哪里？怎么备份？**
- 所有内容都在 AI KP 文件夹里的 `data` 文件夹：团、记录、剧本、设置和 API key。
- 备份就复制整个 `data` 文件夹。
- 这个文件夹里有 API key 和剧本秘密，**不要发给别人**，也不要上传到网上。

**我自己也想当玩家，会被剧透吗？**
- 不会。组织者页面不显示任何剧本秘密。
- 开团时把自己也写进玩家名单，用你自己的邀请链接进入玩家页面玩就行。
