AI KP 的第一个可下载版本：让 AI 当跑团 KP，组织者也不会被剧透。

## 怎么用（Windows）
1. 安装 [Node.js](https://nodejs.org) 的 **LTS 版**（22.13 或更高）。
2. 下载下面的 **ai-kp-v0.4.0.zip**，右键 → **全部解压缩**。
3. 打开解压出来的文件夹，双击 **Start-AI-KP.bat**。
   - 如果 Windows 弹出安全提示，点 **"更多信息" → "仍要运行"**，或者在提示框里点 **"运行"**。
4. 浏览器会自动打开 http://127.0.0.1:3100 。打开文件夹里的 `data\admin-token.txt`，把里面的管理令牌复制到页面右上角，点"连接"。
5. 之后的步骤（填 API key、导入剧本、开团、邀请玩家）请看文件夹里的 **使用说明.md**。

不需要安装别的东西，也不需要输入任何命令。macOS / Linux 用户在终端里进入解压后的文件夹，运行 `sh start.sh`。

## 这个版本能做什么
- **接入剧本**：导入 TXT / Markdown 剧本，AI 自动整理出只给 KP 看的指南，同时生成一份无剧透简介。
- **AI 主持**：玩家只描述行动，检定和掷骰都由 AI 决定。程序会阻止 AI 重掷来"挑结果"，孤注一掷必须由玩家自己选择。
- **7 种规则**：克苏鲁的呼唤 7 版、D&D 5e、开拓者 2e、PbtA、FATE、黑暗世界 V20、通用 d20。
- **节奏导演**：卡关时给线索，冷落的玩家给机会，威胁逼近时加压。
- **自动压缩**：长团会自动把早期经过写成摘要，压缩阈值可以按团调整。
- **多家模型**：OpenRouter、OpenAI（含兼容接口和中转）、Anthropic、DeepSeek、Google Gemini，可以在设置页里选模型。
- **防剧透**：组织者页面不显示任何剧本秘密；游戏结束后可以解锁复盘。

## 已知限制
- **只能在运行它的那台电脑上玩**：别的电脑或手机暂时进不来。
- **只能导入 TXT / Markdown**：Word 文件需要先另存为 TXT。
- **简介不能保证零剧透**：程序只能拦截照抄秘密的句子。
- **真实模型测试范围有限**：只用 OpenRouter 实测过（Claude Opus 5.5、Gemini 4 Argon、Gemini 3.8 Flash）；DeepSeek、OpenAI、Anthropic 官方接口目前只做过格式测试。

## 数据与隐私
所有数据（团、记录、剧本、API key）都保存在解压文件夹里的 `data` 目录，只在你自己的电脑上。升级到新版本时，把旧文件夹里的 `data` 目录复制到新文件夹即可。
