这一版重点是**主持可信度**：让"不需要真人 KP"更靠得住。

## 新功能
- **玩家做决定要点按钮**：KP 需要你拍板时（比如检定失败后要不要孤注一掷），输入框上方会出现选项卡片。只有点按钮才算数，打字不算；只有被问的玩家能答。
- **防剧透审核**：KP 的每条回复发出前，先由辅助模型检查有没有提前说出剧本秘密。有问题就退回重写，连续两次有问题就拦下这一轮。组织者页面可以按团开关，默认开启。
- **摘要不丢线索**：长团自动写摘要时，程序会核对已发现的线索和出场 NPC 有没有被写丢，丢了就重写或直接补上。
- **模型分工**：剧本整理、KP 主持、数据摘要三种工作，可以在设置里分别选接口和模型。
- **DeepSeek 接口**，以及 OpenAI 的 Chat Completions 兼容模式（适合第三方中转）。
- **玩家输入框变大**：占满整行，会随内容长高，没发出的草稿刷新后还在。
- **开发者评测**：`npm run eval -- --scenario 剧本文件` 用真实模型跑一组固定行动，只输出指标（失败、检定、防剧透、费用），不含剧情。

## 怎么用（Windows）
1. 安装 [Node.js](https://nodejs.org) 的 **LTS 版**（22.13 或更高）。
2. 下载下面的 **ai-kp-v0.5.0.zip**，右键 → **全部解压缩**。
3. 双击 **Start-AI-KP.bat**。如果 Windows 弹出安全提示，点 **"更多信息" → "仍要运行"**。
4. 之后的步骤看文件夹里的 **使用说明.md**。

**从 v0.4.0 升级**：把旧文件夹里的 `data` 文件夹复制到新文件夹即可，团、剧本和设置都会保留。

## 已知限制
- 只能在运行它的那台电脑上玩；多人联机下一步会先通过 **QQ 群**实现。
- 只能导入 TXT / Markdown，Word 文件需要先另存为 TXT。
- 防剧透审核本身也是 AI，偶尔会误判或漏判。
- 真实模型测试主要在 OpenRouter 上做过（Claude Opus 5.5、Gemini 4 Argon、Gemini 3.8 Flash）；DeepSeek、OpenAI、Anthropic 官方接口目前只做过格式测试。
