# v0.2 浏览器游玩验收

2026-10-24，本机 IAB 浏览器，独立 `data/preview-v02/` 演示数据。使用本地 Mock 导演与真实后台规则/剧情引擎，无云模型或真实 QQ 消息。

## 双玩家自然语言冒险

以两个独立标签页加入同一 `lantern-vault@2.0.0` 房间，角色为林舟、陈棠。两位角色分别收到不同个人札记，其他角色的札记未出现在本人视图。

实测轨迹：

| 版本 | 玩家/输入 | 实际结果 |
|---|---|---|
| 1、2 | 两位玩家加入 | 身份与个人信息分别隔离 |
| 3 | 林舟：建议调查旧箱 | 出现待确认提案；背包未变化；另一标签页无确认按钮 |
| 4 | 林舟点击本人确认 | 调查旧箱，铜铃+1，首项目标完成，公开铃声线索 |
| 5 | 林舟：进入地窖 | 场景切换到潮湿地窖 |
| 6 | 林舟：如果我摇响铜铃会怎样？ | 澄清，无摇铃/解锁效果，蓝灯室路径仍隐藏 |
| 7 | 林舟：摇响铜铃 | 守卫放下武器，解锁蓝灯室，第二项目标完成 |
| 8 | 林舟：进入蓝灯室 | 场景切换到蓝灯室 |
| 9 | 林舟：修复灯芯 | 后台剧情检定 d20(10)+3 / DC10 成功，扣1体力，第三项目标完成 |
| 10 | 陈棠：点亮蓝灯 | won / 归航之灯，四项目标完成；两个标签页同步结局 |

结局后，移动/手动状态操作/房主管理按钮禁用，输入框保留聊天功能。全程使用文字和提案确认，没有以手动规则按钮代替自然语言路线。

## 集成问题与修正

- 新旧剧本包可按具体版本选择创建，默认新冒险2.0.0，原1.0.0仍可选择。
- 后台实际的 decision 事件已映射为中文“行动解析”。
- 中途发现 Mock 把旧 KP 段落递归拼入新叙述；后端已改为只使用本轮批准事实，并独立限制上下文与输出长度，自动测试包含40轮不递归检查。最终版另行重启核对。
- 真实 provider 的对象键顺序比较已改为结构语义比较；三家模拟协议集成使用逆序对象验证，非法额外字段仍拒绝。

## 边界

这是两个本地标签页的模拟玩家游玩验证，不等于两个真人的体验评测，也不证明真实云模型的语言质量。战斗通关、撤退、触发去重、失败重试和其他边界由后端测试与可复现脚本另行覆盖。真实模型、真实QQ、远程部署与完整D&D均未联调。

## 最终构建复验

- 最终后台启动后，health明确返回应用版本0.2.0。
- 先前双玩家通关房间重载仍为版本10，won与归航之灯保留。
